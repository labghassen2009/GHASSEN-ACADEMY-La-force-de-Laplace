# GHASSEN-ACADEMY-La-force-de-Laplace
GHASSEN ACADEMY est une plateforme éducative moderne dédiée à la force de Laplace. Développée avec React, TypeScript et Three.js, elle offre un laboratoire virtuel 3D interactif, des graphiques dynamiques et un cours complet pour une expérience d'apprentissage immersive et professionnelle.
